# 🏨 سامانه مدیریت تاسیسات هتل

سامانه‌ی یکپارچه‌ی مدیریت خرابی‌ها و تاسیسات هتل با سه پنل مجزا: خانه‌داری، تاسیسات و مدیریت.

## ✨ ویژگی‌ها

### پنل خانه‌داری
- ثبت خرابی با کد رهگیری یکتا (ISS-XXXX)
- آپلود عکس از خرابی (با فشرده‌سازی خودکار)
- اولویت‌بندی (کم، متوسط، زیاد، فوری)
- دسته‌بندی (برق، تأسیسات آب، تهویه، نجاری و ...)
- لغو خرابی‌های در انتظار
- امتیازدهی ۵ ستاره‌ای به کیفیت رفع

### پنل تاسیسات
- دریافت اعلان بلادرنگ هنگام ثبت خرابی جدید
- پذیرش خرابی و شروع رسیدگی
- ثبت رفع با عکس و توضیحات
- محاسبه خودکار زمان رفع
- مشاهده تاریخچه کارهای انجام‌شده

### پنل مدیریت
- داشبورد پیشرفته با ۸ کارت KPI
- نمودارهای تحلیلی (روند روزانه، دسته‌بندی، اولویت، اتاق‌ها)
- جدول امتیازات نیروهای تاسیسات (سرعت ۶۰٪ + کیفیت ۲۵٪ + حجم کار ۱۵٪)
- آرشیو کامل با فیلتر و جستجو
- مدیریت کاربران (افزودن، ویرایش، فعال/غیرفعال، حذف)
- مدیریت اتاق‌ها

### امکانات کلی
- تم تیره/روشن
- واکنش‌گرای کامل موبایل/دسکتاپ
- چیدمان RTL و فونت فارسی Vazirmatn
- احراز هویت با JWT (بدون نیاز به ذخیره‌سازی سشن در حافظه)

## 🚀 راه‌اندازی برای استفاده‌ی دائمی (Vercel + Turso)

این راهنما مخصوص کاربرانی است که تجربه‌ی فنی زیادی ندارند. قدم به قدم پیش برید.

### آنچه نیاز دارید:
- یک حساب ایمیل (Gmail یا هر ایمیل دیگه)
- ۵ دقیقه زمان

---

### قدم ۱: ساخت حساب در Turso (برای دیتابیس رایگان)

1. به سایت [turso.tech](https://turso.tech) برید
2. روی **"Sign up"** کلیک کنید
3. با حساب GitHub یا Google وارد بشید (پیشنهاد: Google)
4. بعد از ورود، به dashboard منتقل می‌شید
5. روی دکمه‌ی **"New database"** کلیک کنید
6. در فیلد **Name** بنویسید: `hotel-facility`
7. در فیلد **Group** مقدار `default` رو انتخاب کنید
8. روی **"Create"** کلیک کنید
9. حالا در صفحه‌ی دیتابیس، روی دکمه‌ی **"libSQL URL"** کلیک کنید و URL رو کپی کنید
   - چیزی شبیه: `libsql://hotel-facility-your-username.turso.io`
10. در همین صفحه، به تب **"Tokens"** برید و یک توکن جدید بسازید
    - روی **"Create auth token"** کلیک کنید
    - توکن رو کپی کنید (مثل: `eyJhbGciOi...`)
11. این دو مقدار رو در یک فایل notepad ذخیره کنید:

```
DATABASE_URL=libsql://hotel-facility-xxxx.turso.io
TURSO_TOKEN=eyJhbGciOiJIUzI1NiIsInR5cCI6...
```

---

### قدم ۲: ساخت حساب در Vercel (برای هاستینگ رایگان)

1. به سایت [vercel.com](https://vercel.com) برید
2. روی **"Sign Up"** کلیک کنید
3. روی **"Continue with Email"** کلیک کنید (یا با GitHub/Google)
4. ایمیل و رمز عبور وارد کنید
5. به ایمیل خود برید و روی لینک تأیید کلیک کنید
6. حالا وارد dashboard شده‌اید

---

### قدم ۳: دریافت کد پروژه

شما باید کد پروژه رو دانلود کنید. دو راه دارید:

#### راه الف: دانلود فایل ZIP (ساده‌ترین)
- از طریق صندوق دانلود (در همین چت) فایل ZIP رو بگیرید
- آن را در کامپیوتر خود extract کنید

#### راه ب: استفاده از GitHub (اختیاری - اگر در آینده می‌خواهید تغییر بدهید)
- یک حساب در [github.com](https://github.com) بسازید
- کد رو در یک repository آپلود کنید
- سپس در Vercel، GitHub رو به حساب متصل کنید و repository رو انتخاب کنید

---

### قدم ۴: ساخت حساب در Vercel و آپلود پروژه

#### روش ۱: با GitHub (پیشنهادی برای آینده)
1. در GitHub یک repository جدید بسازید (مثلاً `hotel-facility`)
2. تمام فایل‌های پروژه رو در آن آپلود کنید
3. به Vercel برگردید
4. روی **"Add New"** → **"Project"** کلیک کنید
5. repository خودتون رو انتخاب کنید
6. در صفحه‌ی تنظیمات، به بخش **"Environment Variables"** برید و این مقادیر رو وارد کنید:
   - `DATABASE_URL` = (libsql URL از Turso)
   - `TURSO_TOKEN` = (توکن از Turso)
   - `SESSION_SECRET` = `my-hotel-secret-2024-change-me`
7. روی **"Deploy"** کلیک کنید
8. صبر کنید تا build تموم شه (۲-۳ دقیقه)
9. لینک سایت شما آماده‌ست! (مثل: `hotel-facility-xxx.vercel.app`)

#### روش ۲: با Vercel CLI (بدون GitHub)

اگه GitHub نمی‌خواهید:

1. [Node.js](https://nodejs.org) رو نصب کنید (نسخه‌ی LTS)
2. Command Prompt یا Terminal (در ویندوز: PowerShell) باز کنید
3. این دستور رو وارد کنید:
```bash
npm install -g vercel
```
4. به پوشه‌ی پروژه برید:
```bash
cd path/to/project
```
5. دستور زیر رو وارد کنید:
```bash
vercel
```
6. اولین بار ازتون می‌پرسه:
   - `Set up and deploy?` → **Y** بزنید
   - `Which scope?` → انتخاب پیش‌فرض
   - `Link to existing project?` → **N** بزنید
   - `What's your project's name?` → `hotel-facility` بنویسید
   - `In which directory?` → Enter بزنید (پیش‌فرض)
7. حالا environment variables رو ست کنید:
```bash
vercel env add DATABASE_URL production
# وقتی پرسید، libsql URL رو paste کنید

vercel env add TURSO_TOKEN production
# وقتی پرسید، توکن رو paste کنید

vercel env add SESSION_SECRET production
# وقتی پرسید، یک رشته‌ی تصادفی بنویسید
```
8. حالا deploy کنید:
```bash
vercel --prod
```
9. بعد از ۲-۳ دقیقه، لینک سایت شما آماده‌ست!

---

### قدم ۵: مقداردهی اولیه‌ی دیتابیس (seed)

بعد از deploy:

1. آدرس سایت خودتون رو در مرورگر باز کنید:
   - مثل: `https://hotel-facility-xxx.vercel.app`
2. در آدرس‌بار، به انتهای آدرس این رو اضافه کنید: `/api/seed`
   - مثل: `https://hotel-facility-xxx.vercel.app/api/seed`
3. Enter بزنید
4. باید این پیام رو ببینید:
```json
{
  "ok": true,
  "message": "دیتابیس با موفقیت مقداردهی اولیه شد",
  "users": 6,
  "rooms": 10
}
```

### قدم ۶: ورود به سامانه

حالا به صفحه‌ی اصلی برگردید و با یکی از حساب‌های پیش‌فرض وارد شوید:

| نقش | نام کاربری | رمز عبور |

| تاسیسات ۱ | `facility1` | `123456` |

## ⚠️ نکات مهم

### امنیت
- **حتماً** رمز عبور پیش‌فرض (`123456`) رو از پنل مدیریت → کاربران → ویرایش تغییر بدید
- `SESSION_SECRET` رو به یک رشته‌ی تصادفی و طولانی تغییر بدید
- برای production واقعی، یک کاربر مدیر بسازید و کاربر `manager` پیش‌فرض رو غیرفعال کنید

### محدودیت‌های پلن رایگان

**Vercel (رایگان همیشگی):**
- ✅ ۱۰۰ گیگابایت پهنای باند در ماه
- ✅ ۱۰۰۰ ساعت اجرا در ماه (خیلی کافیه)
- ⚠️ در پلن رایگان، اگه ۱۵ دقیقه ترافیکی نباشه، سرور به خواب می‌ره (ولی برای پروژه‌ی هتل مشکلی نیست چون ترافیک دائم داره)

**Turso (رایگان همیشگی):**
- ✅ ۵۰۰ دیتابیس
- ✅ ۹ گیگابایت فضای ذخیره‌سازی
- ✅ ۱ میلیارد خواندن در ماه
- ✅ ۲۵ میلیون نوشتن در ماه
- برای پروژه‌ی هتل شما کاملاً کافیه

### اعلان‌های بلادرنگ
در محیط production:
- اعلان‌ها با **Polling** (هر ۸ ثانیه) کار می‌کنند (نه WebSocket)
- یعنی ممکنه تا ۸ ثانیه طول بکشه تا تاسیسات از خرابی جدید باخبر بشه
- برای کاربرد عادی هتل، این کاملاً کافیه
- اگه می‌خواهید WebSocket واقعی داشته باشید، باید از پلتفرم‌های پولی استفاده کنید (Railway یا Render)

### Backup
- دیتابیس Turso به صورت خودکار backup می‌شه
- اگه می‌خواهید دستی هم بک‌آپ بگیرید، از dashboard Turso این کار رو بکنید

## 🛠️ توسعه‌ی محلی (اختیاری)

اگه می‌خواهید روی کامپیوتر خودتون تغییر بدید:

### پیش‌نیازها
- [Node.js](https://nodejs.org) نسخه‌ی ۱۸ یا بالاتر
- [Bun](https://bun.sh) (پیشنهادی)

### نصب
```bash
# نصب وابستگی‌ها
bun install

# ساخت دیتابیس محلی SQLite
bun run db:push

# seed داده‌های نمونه
bun run seed

# اجرای سرور توسعه
bun run dev
```

سپس به `http://localhost:3000` برید.
